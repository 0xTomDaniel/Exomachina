23 September 2026. **Verdict: partial.** The baseline does not establish the full Quality authority or ambiguous-effect gate. ## Reproduce the evidence

From the repository root:

```sh
tools/spikes/2026-09-22/arbitration/temporal/.venv/bin/python -B -m unittest discover -s tools/spikes/2026-09-23/temporal-quality-reconciliation -p 'test_*.py' -v
tools/spikes/2026-09-22/arbitration/temporal/.venv/bin/python -B tools/spikes/2026-09-23/temporal-quality-reconciliation/happy_path_probe.py
```

The unit command ran **16 test methods, zero failures and zero errors**. The live command started local Temporal/PostgreSQL, four independent A2A fixtures, a worker and the Director using PostgreSQL/membership ports 31401/31407–31410 and service ports 44002–44025. It shut them down normally, then replayed both histories with `temporalio.worker.Replayer` after engine shutdown. An earlier ordinary iteration exposed a provisional Director Task projection bug (`terminal phase/result mismatch`); the pure projection was fixed before the release-journal correction. `observed.json` summarizes the final run; `live_observed.json` retains the detailed rows and history hashes.

## Remaining gaps and smallest safe proof

- Inconsistent-verdict and ambiguous-outcome live behavior remain **unproved**. The rejected fault-injection tests must not be repeated or reframed. Pure unit decisions and source review are the evidence for those branches.
- A production closure needs Quality Agent Card digest, authenticated service key/credential binding, explicit lookup capability and per-run policy/worker binding. The current fixture closure has only role, endpoint, identity and approval.
- The SQLite journal is a second durable store. Backup/restore, single-owner fencing and recovery after a journal/Temporal partial restore are unproved. The conservative pre-send intent means an interrupted action can become incident even if no request left the worker.
- The Director token remains in Temporal history in this lane copy. Direct engine access and authorization storage need redesign before product use. Incident-to-`failed` projection is unit/source only; failed native child projection is owned by lane 1.
