# Frozen Temporal interpreter under a fresh withheld four-branch graph

23 September 2026. This trial copied the retrospectively corrected Temporal candidate into a new directory, repaired only its shared-fixture paths and local ports, and demonstrated the visible example **before** the withheld A2C graph was disclosed. The visible run accepted r2 after independent Quality, an exhausted run reached authorized abort, a previous version kept its wait, and the original Director A2A Task completed. The 21-file [freeze receipt](freeze.json), inventory SHA-256 `77956a0f7ded1113401017b90e1358b2bd86d951559122e083d3526663d3b83d`, was independently verified and sent to the evaluator before the withheld graph was revealed. [`runtime-dependencies.json`](runtime-dependencies.json) records the external Temporal/PostgreSQL binary hashes and Temporal Python SDK 1.33.0. Neither the frozen interpreter, validator, Adapter, publisher, Director facade, supervisor, nor dependencies changed after the reveal. Both post-reveal documents and the test driver are outside that inventory; verification still returned the same 21-file digest after the run.

The frozen interpreter **passed the fresh composition and execution test**. [`a2c_trial.py`](a2c_trial.py) authored and published a [mixed-scope v4 definition](definitions/withheld-a2c-v4-mixed.json) and a separate [all-clear v5 definition](definitions/withheld-a2c-v5-clear.json). V4 has four named parallel branches, each bound to a distinct running Strands/A2A capability service: two source and two counter. Counter alpha returned `clear`; counter beta returned `requires_scope`. The counter-beta service held its real A2A Task in `working` until A2A `tasks/get` reported all three other Tasks `completed`. The native Temporal child was queried in its `parallel` phase before that gate opened. The typed join started only after all four completed and retained four exact branch artifact digests, four claims labeled by both source instances, and four objections labeled by both counter instances.

The v4 graph routes on `join.requires_scope` **before** synthesis. Its true branch creates an unresolved r1 draft; its false branch creates a resolved r1 draft. Both converge on independent Quality. The repair block permits at most two repairs, with the later synthesis reading the pinned `outcome_mode` input. The same immutable v4 package digest, `02713ad69cdd331e78b8c1b0acb860af26e30eebbc43ad2d684c98cb8577d843`, and child digest, `911e5a4edd64703398e5398c095b2d17778dd54151d4cefc3efa937d75d6e1fb`, produced both outcomes:

| Pinned input | Observed native route and result |
| --- | --- |
| `after_first_repair` | `route_scope:true` → unresolved r1 → negative Quality → repaired r2 → positive Quality → one exact acceptance and one release receipt. The receiver recorded exactly one accepted effect for that r2 digest. |
| `never` | The same true route yielded negative Quality at r1, r2, and r3 → bounded exhaustion → native child `awaiting-director` → authorized current-r3 abort. There was no acceptance and no release row. |

The separate all-clear v5 package took `route_scope:false`, created the resolved r1 draft, passed independent Quality, and released r1 directly. Its **original Director A2A Task ID** ended `completed`. An older visible revision remained `awaiting-director` with the same digest through both publications and a normal supervisor/worker restart, then completed its authorized abort under that original digest. Worker PID was unchanged during the two publications. [`a2c-observed.json`](a2c-observed.json) contains the original Task ID, all remote service identities and branch Task IDs, native completed-node traces, join digests, Quality counts, exact release rows, old-version status, and freeze checks.

There is a meaningful **Director integration gap**. The frozen Director A2A start facade builds the Workflow input itself and does not expose `outcome_mode`. A mixed v4 run reaches a `from_run` repair node that requires that value. Therefore the two same-definition mixed outcomes were started through the direct Temporal Workflow API with the run mode supplied explicitly; they did not have original Director A2A Task IDs. The all-clear run did use the frozen Director A2A route because it never reaches that repair node. This result proves the unchanged interpreter and validator can execute the fresh graph, while the frozen A2A Director interface does not yet carry every typed run input needed for the mixed graph. Any facade correction must be assessed as a separate post-reveal change.

The services are deterministic local Strands/A2A 0.3.0 fixtures. The hold is a test gate inside a separate service, and the fixed catalog binds local endpoints rather than testing future directory discovery. The mixed run's `outcome_mode` is an explicit typed test input; this trial does not prove its production authorization or derivation from a verified agent artifact. It also does not requalify the earlier Temporal recovery gaps under every fault or measure production resource use. No selection documents or prior trial evidence were changed.
