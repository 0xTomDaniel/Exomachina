# S0 package evidence

[Conductor's result](conductor/result.md) is a pinned published-artifact and source inspection. It found `orkes-conductor-queues:2.0.0.rc3` in the v3.32.4 boot JAR and stopped before runtime testing. The two POM snapshots identify the declared dependency and license. No full Conductor JAR, source clone, compiled replacement or server observation is in this bundle.

[Kestra's initial result](kestra/result.md) records a real native v2.0.3 standalone run with JDK 25 and PostgreSQL 16.15, durable restart, observed footprint and bounded dependency-license review. `dependency-inventory.csv`, `pom-license-audit.csv` and `audit_deps.py` document the published POM check; `hello.yml` and `pause.yml` are the native flows. The initial test PostgreSQL binary was installed locally. The [follow-on bundle trial](kestra/package/result.md) copied JDK, Kestra and PostgreSQL helpers into one macOS arm64 host-local runtime and passed one-command restart/resume. That still does **not** prove a clean-machine one-install product package. The full binary/notice/JDK/PostgreSQL review is open. No JAR, JDK, database, config with credentials, source clone or license-key material is included.
