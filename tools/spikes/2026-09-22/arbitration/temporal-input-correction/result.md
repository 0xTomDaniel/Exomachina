# Temporal A2 runtime-input correction (retrospective)

23 September 2026. This is an isolated copy of the frozen Temporal arbitration candidate, changed **after** the original hidden A2 arrangement was known. It does not convert the original A2 result into a blind pass. Its purpose is narrower: determine whether the same immutable graph package can produce one-repair success and two-repair exhaustion through a typed run input without changing the published layout between runs.

The [original](../temporal/result.md) interpreter fixed synthesis resolution in the document. This copy adds one approved `from_run` resolution mode to the validator and interpreter, threads `outcome_mode` from the parent Workflow input into its pinned child, and retains the same independent Quality review and acceptance gates. The v4 document's repair synthesis node uses `from_run`; `after_first_repair` resolves r2 while `never` leaves r2/r3 unresolved. These modes are deterministic Workflow inputs bound to each run, not a worker rollout or changed factory digest. The [source diff](factory.py) is inspectable beside the original frozen source. The test driver was changed to supply the two inputs and authorize abort at the second child's persisted Director wait.

The [observed result](hidden-observed.json) reports `retrospective_fix_pass`: one v4 run accepted and released r2; another run of **the same child digest** `04204ff8d995ef7094ac0df3ad88a225bf408d89df29470038beb5f7c5533c93` reached r3 and returned `aborted` after an authorized Director command, with no acceptance or release. V5 clear accepted r1. An older v3 child kept its wait and digest across publication and a normal restart. The worker PID remained unchanged during publication. The new 18-file source inventory SHA-256 `74a62c9adccde14a16e985f8f0cca7ad2020971c3b750ac7d4cec2c64e450ea2` verified before and after the run. Raw local state is recorded in the observed JSON. The first invocation produced the divergent outcomes but failed only on the old driver's assertion that the second run must accept r2; the corrected driver passed from fresh state.

This is a feasibility check, **not** a new unseen arrangement or full product contract. The driver supplied a deterministic outcome mode directly; a real factory must bind that value to an authorized brief or agent artifact with schema and provenance checks. The second run started by direct Workflow API and received a direct authorized Update; this trial does not add the missing post-commit Director A2A recovery or active Quality-result-negative evidence. Interpreter replay compatibility with retained histories after this code change was not tested. The original frozen failure and all remaining [Temporal arbitration gaps](../temporal/result.md) still stand.
